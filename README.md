# WoodAccountingSystem

WPF-приложение для учёта древесины на складах: добавление и удаление складов, загрузка и выгрузка древесины, контроль свободного места.

## Установка

1. Установить Visual Studio.
2. Установить .NET Framework.
3. Открыть `WoodAccountingSystem.sln` в Visual Studio.
4. Настроить подключение к базе данных SQL Server.
5. Собрать проект.

## Использование

1. Запустить приложение (F5).
2. Открывается список складов.
3. Кнопка «Добавить» — создание нового склада.
4. Кнопка «Удалить» — удаление пустого склада.
5. Клик по складу — переход в карточку склада.
6. В карточке — загрузка и выгрузка древесины.

## Структура проекта
 
- `Views/`: Страницы приложения.
- `Infrastructure/`: Файл представленный классом с методом для проверки корректности ввода. 
- `Entities/`: Модель данных. 

## Данные

Приложение использует базу данных SQL Server через Entity Framework. Основные сущности:

- Storage: Склад (номер, вместимость).
- Wood: Древесина (название, сорт).
- Wood_in_Storage: Запись о хранении (склад, древесина, объём).
